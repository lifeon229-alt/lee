어비스 반복 — 사용법
====================

1. 이 폴더(AbyssBot)를 원하는 곳에 둡니다. 예: C:\AbyssBot  (한글이 없는 경로 권장)
2. AbyssBot.exe 실행 → "예"(관리자 권한 허용).
   처음 실행하면 '준비 상태' 창이 자동으로 열립니다.
3. 준비 상태 창에서 빨간 항목을 해결합니다.
   - 한국어 OCR: [설치] (수 분 걸릴 수 있음)
   - 입력 드라이버(Interception): [설치] → 재부팅
   - 게임 창: 게임을 켠 상태에서 목록에서 게임 창을 고르고 [이 창 사용]
   모두 초록색이면 준비 끝입니다. 이 창은 위쪽 '준비 상태' 버튼으로 언제든 다시 열 수 있습니다.
4. 게임은 '테두리 없는 전체 화면 1920×1080'으로 둡니다.
5. 처음에는 목표 횟수를 1로 두고 시험합니다.
   게임 메인화면(캐릭터가 서 있는 상태)에서 [시작] → 3초 안에 게임 창을 클릭.
   F10을 누르면 언제든 즉시 멈춥니다.
6. 잘 되면 목표 횟수를 0(무제한)으로 두고 사용합니다.

문제가 생기면
- logs\abyss.log, errors 폴더(멈춘 순간의 화면 사진과 원인)를 확인하거나 전달해 주세요.
- 화면 캡처 저장 → 화면 검증 으로 인식이 맞는지 입력 없이 확인할 수 있습니다.

주의
- 입력 드라이버와 자동화 프로그램은 게임 보안 프로그램에 감지되거나 이용약관에 어긋날 수 있습니다.
  계정 제재 위험은 사용자가 감수해야 합니다.
- 재화 구매나 구매 확인은 자동으로 누르지 않습니다.
